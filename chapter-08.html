第 7 章：准备第一个实验

实验的范围

我们运行固定的演示程序，不让模型生成任意代码。任务是计算三笔收入：120、80、50，预期总额为 250。所有数据都是虚构的。实验能帮助理解限制如何作用，不能证明一台机器可以安全执行任何陌生代码。

需要准备 Docker 和 Python 3。macOS 或 Windows 用户可以安装 Docker Desktop；Linux 用户可按官方文档安装 Docker Engine。下面命令使用 macOS、Linux 或 WSL 的 shell；Windows PowerShell 用户请在 WSL 里操作。安装和启动 Docker 按对应操作系统官方说明完成。

先在终端执行：

docker version
python3 --version

如果 Docker 只显示客户端信息并提示无法连接服务，先启动 Docker 服务。以下命令会从镜像仓库下载 Python 官方镜像，需要网络和一定磁盘空间：

docker pull python:3.12-slim

这个标签会随时间变化。入门阶段方便理解即可；需要复现实验时，应记录镜像 ID 或摘要，并在自己的项目里固定经过验证的摘要。

建立专用目录

为本实验单独新建目录，不要在已有重要文件的目录里操作：

mkdir agent-sandbox-demo
cd agent-sandbox-demo
mkdir input output

后面会生成四个文件：input/sales.csv、input/analyze.py、run_demo.py 和 output/report.json。先建立脚本和数据，最后才启动容器。

不要在不熟悉的命令中加入 –privileged，也不要挂载整个磁盘。本实验只给容器两个特定目录，并使用演示数据。
