阅读路线：先理解，再动手

如果你完全没有编程基础，请按顺序阅读第 1～6 章。暂时看不懂命令没有关系，先弄清楚“谁提出动作、谁执行动作、谁限制动作”。

第 7～9 章是可选的本地实验：使用 Docker 运行一段固定的 Python 程序，观察权限限制。实验不需要大模型账号，也不需要 API 密钥。它模拟智能体的一次工具调用，因此你能先学会执行环境，再接入模型。

第 10～13 章解释真实系统如何管理生命周期、文件、网络和异常。第 14 章给出选择方法，第 15 章提供基础七天学习安排。第 16～22 章重点解析 OpenSandbox、SPACE、CubeSandbox 与 Anthropic sandbox-runtime，包含架构、源码入口、差异与选型练习。第 23～27 章补充同类平台、底层工具、论文导读、评测框架与第二阶段学习路线。附录包含答案、术语、原始资料、固定提交的源码阅读索引，以及扩展资料核查记录。

阅读目标不是背下产品名，而是能回答四个问题：这次任务可以读什么、可以改什么、可以连接哪里、何时必须停止？
