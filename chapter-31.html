附录 C：资料来源与继续阅读

本书优先查阅项目官方文档及官方工程文章。查阅日期：2026-10-20（工作环境日期）。这里给出本次查阅的页面或官方文档源文件，不宣称覆盖所有方案，也不把厂商文章视为独立安全认证。项目可能持续变动，请以访问时的文档和你使用的版本为准。

正文的 [1]～[10] 对应以下基础来源，[11]～[14] 对应附录 D 的工程仓库。基础概念和机制说明基于这些资料；教学案例、学习安排、设计建议及练习答案为本书编写。内容是释义与综合，不是逐句引用。

[1] Docker：Docker Engine security。理解容器隔离、守护进程攻击面、权限与内核安全机制。用于第 3、4、6 章。

https://docs.docker.com/engine/security/

[2] Docker：Seccomp security profiles for Docker。理解默认系统调用过滤与自定义配置。用于第 4 章。

https://docs.docker.com/engine/security/seccomp/

[3] Docker：docker container run。核对 –mount、–read-only、–network、–memory、–cpus、–pids-limit 等参数。用于第 4、7～9 章。

https://docs.docker.com/reference/cli/docker/container/run/

本次该网页连接不稳定，参数核对使用 Docker 官方 CLI 仓库中的同源文档：

https://github.com/docker/cli/blob/master/docs/reference/commandline/container_run.md

[4] Anthropic：Claude Code sandboxing 工程文章。观察智能体产品如何结合文件系统和网络隔离。用于第 6 章。

https://www.anthropic.com/engineering/claude-code-sandboxing

[5] gVisor：Documentation。理解应用内核与隔离路线，并继续查看兼容性和架构文档。用于第 3、6 章。

https://gvisor.dev/docs/

[6] Firecracker：项目官网与其链接的架构、设计及生产部署资料。理解 microVM、KVM 和精简设备模型。用于第 3、6 章。

https://firecracker-microvm.github.io/

[7] E2B：官方文档。认识面向 AI 代码执行的托管沙箱接口。用于第 3、6 章。

https://e2b.dev/docs

[8] Kubernetes SIGs：agent-sandbox 官方仓库。认识 Kubernetes 生态中的沙箱生命周期与管理项目。用于第 6 章。

https://github.com/kubernetes-sigs/agent-sandbox

[9] OWASP GenAI Security Project：LLM01 Prompt Injection。理解提示注入、外部内容与应用权限的关系。用于第 5 章。

https://genai.owasp.org/llmrisk/llm01-prompt-injection/

[10] Docker：Rootless mode。理解非 root 运行模式的适用条件与限制。用于第 6 章。

https://docs.docker.com/engine/security/rootless/

继续阅读建议：先把 Docker 参数与本书实验逐个对照，再阅读 gVisor 或 Firecracker 的架构资料。如果准备使用云平台，先核对创建、销毁、联网、文件传输和数据保留规则，再接入真实数据。
